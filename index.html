题库格式说明

Excel / CSV 直接丢进来就行。只要表头里有「题干」和「答案」两列，其余靠猜：

  • 题型列可以叫题型 / 类型，值写「判断题、单选题、多选题、填空题」；不写也行，程序看有没有选项自动判断
  • 选项列叫选项A…选项H，或者精简成 A,B,C,D；也可以只留一列「选项」，里面一行一个
  • 答案列叫正确答案 / 答案 / 参考答案；多选写 A,C 或 AC，判断写 对/错 或 √/×
  • 解析列叫解析 / 答案解析 / 说明，有就显示，没有就空着
  • 表头上方有标题行、左边有序号列都没关系，会自动跳过；多个 sheet 会合并

解析完会先给你看一眼：多少题、各题型多少、去重几条、修了什么、跳过哪些，确认后才真正换题库。

JSON 写法：一个数组，每题四个字段。

[
  {
    "type": "single",
    "stem": "企业年度结账日为（　）。",
    "options": ["12月31日", "农历最后一日", "任意日期"],
    "answer": ["A"],
    "explanation": "《会计基础工作规范》第六十二条"
  }
]

type 支持：judge 判断、single 单选、multiple 多选、blank 填空、short 简答。不写 type 会自动判断。

CSV 表头示例：题型,题干,选项A,选项B,选项C,选项D,正确答案,解析
