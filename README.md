# 小赵勇争第一

本地刷题 App（用浏览器打开即可）。内置一份示例题库，也可以换成自己的。题库和练题记录只写在浏览器 `localStorage` 里，不经过服务器，也不上传。

## 打开

用浏览器直接打开仓库根目录的 `index.html`。Android 封装见 `android/`。

## 换一份题库

1. 在首页统计条里点「题库」，进入题库页。
2. 找到「换一份题库」：把文件拖进虚线框，或点「选择文件」；也可以把 JSON / CSV 文本粘贴到输入框，再点「解析这段文本」。
3. 先看预览（题量、题型、去重和跳过），确认后才会真正换上。

支持 `.xlsx`、`.csv`、`.tsv`、`.txt`、`.json`、`.js`。表格必须有「题干」和「答案」两列（「题目」「正确答案」这类相近表头也可以）。旧版 `.xls` 请先另存为 `.xlsx` 或 CSV。

预览里：

- **替换现有题库**：整份换成这份新题。同一道题（题干 + 题型）已有的练题记录会保留。
- **追加合并**：新题接到当前题库后面；题干和题型都相同的不重复加入。

题库页上的「恢复内置题库」：确认后丢掉当前导入的题库，回到应用自带的那份。同页的「导出题库」会下载当前题库的 JSON。

## 题库格式

写法以 `data/bank.json` 为准：

```json
{
  "title": "题库名称",
  "questions": [
    {
      "id": "q1",
      "type": "single",
      "stem": "题干",
      "answer": ["A"],
      "explanation": "可选"
    }
  ]
}
```

`type` 取 `judge`（判断）、`single`（单选）、`multiple`（多选）、`blank`（填空）、`short`（简答）。单选和多选另有 `options`。也可以只给题目数组。页面里「题库格式说明」有表格列名和答案写法。
