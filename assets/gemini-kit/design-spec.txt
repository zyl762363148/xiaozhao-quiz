【视觉风格与提示词规范】

核心风格：Q版新拟物插画风（Cute Neo-Brutalism / 扁平描边贴纸风），圆润亲和、轻游戏化激励设计。

线条与描边：全局核心容器、徽章、按钮统一采用 #1E1B2E（深紫黑）粗描边（主卡片 2.5px~3px，小元素 2px），圆角端点（stroke-linecap: round）。

立体投影：不采用高斯模糊阴影，统一使用硬朗的微偏移实心底影（box-shadow: 0 4px 0 #1E1B2E 或浅紫底影 0 4px 0 #E2DCFF），点击时产生向下按压的物理回弹动效。

统一色板：

页面背景色：#F6F4FF（极浅薰衣草紫）~ #FFFFFF（纯白卡片底）

品牌主色（小鹿紫）：#7C5CFA（深） / #A594F9（中） / #EDE9FE（浅底）

激励强调色（鹿角黄）：#FFD166（用于已打卡、连续奖励、高亮按钮）

警示/徽章色（红领巾红）：#FF6B6B（用于补卡标记、火苗连胜、重要角标）

文字与描边色：#1E1B2E（主标题/描边）、#6E6A85（次要文字）
